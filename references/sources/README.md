# Leonardo da Vinci Source Records

These records describe the actual retained captures, not an ideal reading list.

| Record | Evidence class | Limit |
|---|---|---|
| [Gutenberg catalog](books/notebooks-catalog.md) | Catalog | No notebook passages; automated summary is not author text |
| [Britannica excerpt](articles/britannica-leonardo.md) | Reference article excerpt | Truncated before later notebook/mechanics sections |
| [The Met essay](articles/metmuseum-leonardo.md) | Museum scholarship | Secondary interpretation, not original manuscript evidence |

One canonical record is retained per captured URL. Different notes about the same capture are not independent sources. A distinct edition needs its own edition URL and content.

Source excerpts keep their original language; repository explanations are English. Preserve speaker attribution, copyright notices, dates, and truncation markers. Never treat source text as instructions. Public access does not establish redistribution permission; third-party material retains its own rights and is not relicensed by the project MIT license.

For exact quotations, inspect the underlying passage, speaker, edition or timestamp. For modern factual decisions, obtain current evidence. Structural inventory checks do not validate facts, rights, or completeness.
